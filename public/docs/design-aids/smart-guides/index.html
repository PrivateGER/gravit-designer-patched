Design aids

Smart guides

Smart guides

Smart guides display temporarily when you’re creating or moving objects or anchor points, allowing for fast and precise alignment. They are automatically shown when the Use Snapping option is enabled. The type of Smart guides displayed depends on which snapping options are enabled.

Note: Smart guides don’t work for objects outside of the page or canvas.

 

Note: The snapping of an element inside a group is limited only to elements of that group or Layer group.

 

By default, Corel Vector displays Smart guides to snap to any edge or center of an object when creating, moving, or resizing objects. The distance to nearby objects is also displayed. Smart guides are also shown when there is equal distances between objects.
